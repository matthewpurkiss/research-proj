\section{Reproducibility}

The code and data are in a private GitHub repository, available on request. The data used for every result is frozen with SHA-256 checksums under the git tag \texttt{data-freeze-2026-10-07}, and the 2026 forward data is recorded separately in the same freeze file. The pipeline runs in order: data fetch and dataset build, leakage audit and mutation test, Alpha and baseline training, Beta Agent training and Platt scaling, the GARCH and skill-score comparisons, the backtest with its grid search, and finally the Phase 5 scripts for the significance tests, ablations, stress test, forward test and direction baselines. The experiments used Python 3.9.6, PyTorch 2.8.0, pandas 2.3.3, NumPy 1.23.5, yfinance 1.2.0 and arch 7.2.0 for GARCH.

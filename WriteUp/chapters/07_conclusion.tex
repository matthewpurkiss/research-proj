\section{Future work}
\begin{guide}
Concrete, each tied to a finding:
\begin{itemize}
  \item cap stop distance below the liquidation level (from the 20x stress test);
  \item recalibrate the volatility forecast on validation data to remove its upward bias (like Platt scaling for the jump probability);
  \item model slippage, weekend gaps and CFD financing costs;
  \item test on more assets (ETH, other coins) and longer forward periods;
  \item feed the Risk Engine a better direction signal if one is found - the framework is modular, so the Alpha Agent can be swapped without touching the risk side.
\end{itemize}
\end{guide}
